# İmleç, arka plan ve dock dili

- `turk.ani`: Fare > İşaretçiler > Normal Seçim > Gözat ile seçip uygulayın.
- `ULUTURK.jpg`: Kişiselleştirme > Arka Plan üzerinden seçin; yerleşim Genişlet.
- `Dock-Turkce` içindeki üç INI dosyasını, dock kapalıyken `lang` klasöründekilerin üzerine yazın. Dosyaları silmeyin; varsayılan Çince yeniden oluşturulabilir. Metinler aynı Türkçe çeviridir, dil adları korunur.

Varlıklar proje sahibi tarafından sağlandı; ayrıca bir eser sahipliği/lisans incelemesi yapılmadı. Dock çalıştırılabilir dosyaları bu indirmelerde yoktur.
